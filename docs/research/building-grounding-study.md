# 건물이 땅에 붙어 보이게 하는 것: 사진측량 스캔 vs 부산 (11-12)

문제: V-World 사진 위의 3D 건물이 "붕 떠" 보인다. 실제 도시를 찍은 사진측량 스캔 2개를 Blender 에서 부산 장면과 같은 자로 재고,
어떤 고침이 차이를 가장 많이 줄이는지 정했다. 미리보기 페이지 (로컬): http://127.0.0.1:8767/today/busan_grounding_study/

## 결론
1. 스캔에서 건물 옆 땅이 어두운 이유는 **해 그림자**와 **텍스처에 구워진 어둠**이다.
   - 해 그림자를 끄면 땅 접지 대비 (발자국 1–2.5 m ÷ 15–30 m) 가 −3.05 → −1.51 (TUM), −2.25 → −1.19 (Avenue) stop.
   - 텍스처만 놓고 보면 건물 옆 땅이 먼 땅보다 1.4 stop 어둡다 (두 스캔 모두).
   - 해 비치는 땅에서는 이 텍스처 어둠이 전부다. 땅을 한 색으로 바꾸면 −1.68 → −0.10, −0.81 → 0.00 이 된다.
   - TUM 은 12월에 찍어 해가 낮았다. 그래서 '구운 어둠' 의 상당 부분은 찍을 때 생긴 긴 그림자일 수 있다 (추정).
2. **AO** (하늘 가림 + 반사광) 는 장면에 따라 다르다.
   - TUM (좁은 안뜰): −3.05 → −2.28.
   - Avenue (낮은 주택): 변화 없음.
3. **우리 사진**에서는 건물 옆 땅이 먼 땅보다 밝거나 (서면, 해 비치는 곳 +0.23..+0.28) 조금만 어둡다 (광안 −0.3 / −0.6). 스캔은 −0.8..−1.7 이다.
   - 정사가 아닌 사진이라 건물 자기 지붕·벽이 옆 땅에 그려진다.
   - 스캔에 같은 종류의 사진 (12° 기울여 위에서 찍은 자기 사진) 을 넣어 보았다. TUM 은 접지 대비가 −1.68 → −0.59 로 무너진다. 낮은 Avenue 는 변화가 없다. 높은 건물에서만 생기는 문제다.
4. **고침**: 땅 쪽 두 가지와 벽 쪽 하나를 같이 쓴다.
   - 땅 (a'): 발자국 + 2 m + 기울기 구역의 사진을 ×0.4 로 어둡게 한다 (무늬는 유지).
   - 땅 (b): 접지 띠 1 − 0.55·exp(−d / 6 m).
   - 벽 (c): 발밑 1 − 0.45·exp(−z / 4 m).
   - 효과: 스캔과의 차이 점수가 1.95 → 1.20 (−38 %, 6장 평균) 으로 줄고, 6장 모두 좋아진다.
   - 하나씩만 쓴 경우: a' 1.60, b 1.60, c 1.80.
   - c 만 쓰면 벽 발밑은 스캔 쪽으로 가지만, 벽과 옆 땅의 단차가 커져 효과가 상쇄된다. 그래서 땅을 같이 어둡게 해야 한다.
   - 참고: Blender 에서 진짜 GI (Lumen 이 건물을 보는 경우) 를 켜면 1.65 다. 땅 고침 하나와 비슷한 크기다.
   - 스캔끼리 잰 차이 점수도 0.5–0.7 이다. 이것이 바닥이다 (목표에 자기 자신이 들어 있어 과소평가).
5. UE: `GYROSIM_BLDG_CONTACT` 기본 켬 (센 값). GPU 차 −0.02..+0.03 ms (= 반복 차), 새 끊김 없음. 아래 'UE' 절.

## 방법 (sim/grounding/)
| 파일 | 하는 일 |
|---|---|
| `busan_scene.py` | 부산 한 곳의 장면 설명 JSON 을 만든다 (건물 glb 경로 + 노드 행렬, 지형 격자, V-World 캐시 타일 경로). 사진은 저장하지 않고, Blender 가 캐시에서 메모리로 읽는다 |
| `render_study.py` | 헤드리스 Blender. `prep` = 0.5 m 격자로 아래로 광선을 쏘아 표면 높이를 만든다. `render` = 모든 머티리얼에 같은 픽셀 로직을 넣는다 (땅 높이, 건물 마스크, 발자국 거리 → AOV + 변형 스위치). 패스는 EXR 로 낸다 |
| `classify.py` | 땅 높이를 정한다. 스캔은 점진 형태학 필터 (Zhang 2003), 부산은 지형 메시를 쓴다. 그 위에 건물 마스크, 거리, 하늘 가림 (bldg_ao_build.py 와 같은 식), 기울기 구역을 만든다 |
| `analyse.py` | 지표 (stop = log2 중앙값) 를 계산하고, 차이 점수와 미리보기 JPEG 을 만든다 |
| `build_page.py` | 미리보기 페이지를 만든다 |
| `ue_contact_ab.ps1` | UE 데이터와 머티리얼을 다시 빌드하고 게임 안 A/B 와 GPU 를 잰다 (lock 하나로) |

- 빛: 해 고도 42°, 방위 215° (Play 기본). 카메라는 3방향이다 (해를 등지고, 옆, 45° 역광). 피치 35–55°, 화면 폭 약 130–420 m, 1280×720, Cycles GPU 96 샘플 + OIDN.
- `ue` 빛 = 하늘빛을 가리지 않고 반사광도 없다. Lumen 이 Cesium 메시를 보지 못하는 UE 상황을 흉내 낸 것이다. 부산 렌더는 기본이 이것이고, `rt` 만 Cycles GI 를 쓴다.
- 부산 기준 (base) 에는 지금 UE 의 벽 발밑 어둡게 (f3: GdBase 0.5 / 8 m, GdGrad 0.6 / 50 m, floor 0.7) 를 같은 식으로 넣었다.
- 차이 점수: 지표 7개 (벽 발밑, 땅 접지 대비 전체 / 해 비치는 곳, 띠 폭, 벽발밑−옆땅 단차, 색 차이, 옆땅 무늬) 를 쓴다.
  - 각 지표가 스캔 원본 6장의 중앙값에서 떨어진 거리를 스캔 사이 퍼짐 (IQR 과 최소값 중 큰 것) 으로 나눈다.
  - 지표마다 3 에서 자른 뒤 평균한다.

## 한계 · 가정
- 고친 버그 (11-12): 처음에는 땅 고침이 건물 마스크 (발자국보다 1 m 넓음) 바깥에만 칠해졌다. 그래서 건물 둘레에 고침이 안 된 밝은 1 m 테가 남았다 (감독자가 그림에서 찾음). 땅을 '낮고 위를 향한 면' 으로 고치고 모든 렌더를 다시 돌렸다.
- 지표의 '1–2.5 m 땅' 은 건물 마스크를 1 m 넓혔기 때문에 실제로는 1 m 부터다.
- Blender 의 부산 벽은 glTF 창문 아틀라스로, UE 의 절차 셰이더와 다르다. 색 차이 (부산 4.2, 스캔 2.0) 는 고침과 관계없이 고정으로 남는 몫이다.
- 스캔 텍스처의 구운 그림자는 촬영 때의 해 방향을 따른다.
- 스캔 방위는 진북이 아닐 수 있다 (Sketchfab 모델).
- 스캔은 2개뿐이다. 한국 도심 스캔은 무료·무로그인으로 찾지 못했다.
- 광안 v3 는 먼 땅 (15–30 m) 픽셀이 부족해 일부 지표가 빠졌다.
- 띠 폭 지표는 스캔이 15 m 안에서 회복하지 않아 사실상 이진값이다.
- V-World 사진은 캐시에서 읽기만 했다. 렌더는 미리보기로만 쓰고 git 에 넣지 않는다.

값을 고른 이유:
- Blender 추천값 (×0.4, 0.55 / 6 m, 0.45 / 4 m) 은 게임 화면에서 너무 옅었다. 촘촘한 도심이라 보이는 땅이 좁다.
- 그래서 센 값 (×0.3, 0.7 / 8 m, 0.55 / 5 m) 을 기본으로 했다.
- Blender 에서 이 값의 차이 점수는 1.24 로, 추천값 1.20 과 거의 같다. 땅은 스캔보다 조금 더 어두운 쪽이다.

- 끊김: 10초 동안 30 ms 튐이 끔과 켬 양쪽에 같은 빈도로 나온다. 변형을 바꿀 때 타일을 다시 읽어서 생긴다. p99 는 8.6 ms 로 같다.
- 텍스처 추가 없음, 샘플 추가 없음. 이미 읽는 T_GyroBldgAO 의 A 채널을 쓴다. 상수 몇 개만 늘었다.
- 확인용 과장 변형 (사진 ×0, 띠 1.0) 으로 칠해지는 자리가 건물 둘레 땅뿐임을 확인했다.
- 화면 차이: 같은 Play 경로에서 픽셀의 2.6 % (서면) ~ 4.9 % (광안) 가 30 단위 넘게 어두워진다.
- 반복: GPU 는 '끔' 을 두 번 쟀다. 그림은 한 번씩만 찍었다.

남은 것:
- 고층 기울기 구역은 B 채널 그대로라 높이 20 m 이상만 들어간다. Blender 는 15 m 이상을 썼다.
- VR (CSM) 프리셋에서는 확인하지 않았다.
