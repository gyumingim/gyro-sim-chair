## 잰 것 (같은 자를 실사진과 렌더에)
d = 해에서 떨어진 거리 (화면 **폭** 단위; 사진 화각을 몰라서 각도 대신, 렌더는 70°). 해 쪽 = d < 0.45.
- 해 쪽 건물 밝기 / 해 근처 하늘 (0.06 < d < 0.3) 의 비 (stop), 건물 L* 중앙값·σL*·C*·b*
- 반짝임 = 건물 화소 중 L* ≥ 85 의 비율, 가장 큰 덩어리 크기 (건물 면적 대비), 반짝임 중 건물 윤곽 2 px 안 비율
- d 구간별 하늘·땅 L*, C*, b*, 색상각 (연무), 화면 채도, 해 번짐 반경 (링 중앙값 L* < 90), 해 아래 물비늘 길 (밝은 비율·반폭·바깥 바다와의 L* 차)

## 찾은 원인 (같은 실행 A/B, 구름 고정)
1. **유리 거울**: 해 쪽 건물 반짝임 화소 0.9–2 % (사진 0.1 %), 가장 큰 덩어리가 사진의 3배, 윤곽이 아니라 면 전체.
   노출은 원인 아님: 자동 노출 상한 2.5 → 4.0 EV 는 역광 장면에서 변화 0 (상한에 안 걸림, s1). 히스토그램 비율 바꾸기는 정면광까지 바뀜 → 안 씀.
   랜드마크 유리 변수만 낮추면 랜드마크는 맞지만 a16 의 앞줄 탑은 일반 건물 (style 7 은빛 유리, 금속성 0.6–0.85) 이라 그대로.
2. **누런 연무**: 높이 안개의 해 쪽 산란 (directional in-scatter) 을 꺼도 거의 그대로 (b* −0.5). 숫자상 원인은 대기(SkyAtmosphere) 의
   Mie 앞쪽 산란 봉우리: 해 근처 땅 L* 48 / b* 15 (사진 34 / 6). 비등방성 0.75 는 더 나빠짐, 0.3 이 가장 좋고 0.2 는 거의 같음.
   블룸은 원인 아님 (끄면 해 번짐만 줄고 연무 숫자 그대로).

## 바꾼 것과 값
| 무엇 | 전 | 후 | 이유 |
|---|---|---|---|
| 유리 규칙 (일반 건물·랜드마크) | 없음 | 카메라–해 각도 41° 안 = 전부, 81° 밖 = 0 | 해 쪽을 볼 때만. 정면광 장면은 수식상 0 |

| 유리판 거칠기 | +0 | +0.12 (`BkRough`) | 반사가 흐려져 밝은 덩어리 작아짐 |
| 거울로 남는 판 | 전부 | 3.5 % (`BkKeep`, 판마다 무작위; 멀면 평균) | 사진의 "드문 한 판 반짝임" |
| 유리탑 금속 벽판 (style 6·7) | ×1 | 같은 규칙 | 벽판도 거울처럼 빛났음 |
안 바꾼 것: 블룸·해 원반 (해 번짐 반경 0.025 vs 사진 0.0225, 이미 맞음), 자동 노출, 바다 재질 (아래 "남은 것").
값 고르기: 강하게 (0.1 / 0.4 / 0.2 / 2 %) 는 건물 채도가 사진 아래로 (C* 6.8 vs 8.4), 약하게 (0.35 / 0.7 / 0.08 / 5 %) 는 반짝임 0.4 % — 가운데 값.
실제 유리의 물리 모델이 아니라 사진 통계에 맞춘 보정이다 (실제로는 반사되는 하늘이 해 반대쪽이라 어둡고, 카메라가 밝은 하늘에 노출을 맞춤).

### 블라인드 검토 (새 에이전트, 읽기 전용, 실사진과 비교, A/B 무작위, md5 확인)
1차 (`final`: 유리 + Mie 0.3, 10 시점): 유리 시점 b1 / b2 / b5 = **후 3 (확신 중·높음)** — "전은 면 전체가 파란 하늘을 비추는 거울, 후는 드문 반짝임의 어두운 유리 = 실사진".
연무 시점 a16 / b3 = **전 2** (실사진은 해 근처가 더 뿌옇고 따뜻함, 후의 먼 능선이 너무 또렷). 정면광 3 · a17 · h4 = 같음.
→ **Mie 변경은 되돌림** (아래). 최종 (`final2`) 은 유리만 = 1차에서 이긴 부분.

### 되돌린 것
Mie 비등방성 0.6 → 0.3 + Mie 색 (0.55, 0.74, 1): 숫자는 실사진 쪽 (해 근처 땅 L* 47 → 40, b* 15 → 12) 이었지만 블라인드 검토가
연무 시점 둘 다 전을 골랐고, 정면광 먼 땅이 b* +0.7 따뜻해짐. → `atmos_look.py` 는 그대로 (시험 결과는 주석).
"누런 기운" 은 숫자 (해 근처 땅 b* 15 vs 6) 로는 남아 있으나, 검토자는 실사진의 해 근처가 오히려 더 강하게 따뜻하다고 봄 → 다음 후보는 색이 아니라
해 근처 땅의 밝기 (L* 47 vs 34) 와 그늘 (검토: 역광 그늘이 너무 검푸름, 실사진은 따뜻한 회갈색).

## 남은 것
- 바다 물비늘 길이 실사진보다 훨씬 밝고 넓음 (L* 차 35 vs 8) — 바다 재질 담당 몫 (안 건드림).
- 역광 그늘이 검푸름, 해 주변 빛무리가 작음 (검토자 지적, 측정은 반대: 번짐 반경은 이미 맞음 → 사진의 노출·플레어 차이로 추정).
- 먼 유리탑에 큰 금색 / 파란 덩어리가 아직 조금 (a16) — 판 크기가 화소보다 작아 평균값으로 바뀌는 거리.
- 반짝임이 윤곽보다 면 안쪽 판에 있음 (19 % vs 40 %): 모서리·멀리언 반짝임은 아직 없음.
- VR 은 따로 촬영 안 함 (같은 재질이라 같은 규칙).

## 섞인 변수 · 가정
- 실사진은 대부분 해질녘 (해 0–5°), 렌더는 해 8–15° → 하늘 색 (사진이 더 노랗다: 해 근처 하늘 b* 20 vs 렌더 9–11) 은 이 차이 탓일 수 있어 맞추지 않음 (추정).
- 사진 화각을 몰라 거리를 화면 폭 단위로 씀 (사진 대부분 표준~광각 추정). 사진은 카메라 처리 (노출·HDR·채도) 를 거쳤다.
- 해 위치는 사람이 표시 (화면 밖이면 추정, ±0.03 정도).
- 값은 역광 시점 (s2) 으로 고르고 같은 시점 + 떼어 둔 1 시점 (h4 남항 해돋이) 으로 채점. 블라인드 검토는 1차 (Mie 포함) 결과만 — 유리 부분은 그때와 같은 값.
- 반짝임 기준 L* ≥ 85 는 고정 문턱 — 노출이 다른 사진 사이 비교는 대략적.
