결론
  • 의자는 계산상 pitch 1.1 °/s, roll 1.6 °/s 가 최대입니다 (모터 25 rpm 추정). 시뮬레이터의 8 °/s 는 5~7 배 빨라 실현 불가 → 권장 속도 pitch 0.95 · roll 1.3 °/s, 가속 0.48 · 0.6 °/s², 한계 ±14 · ±18°.
  • 의자 제어 프로그램(PC 다리 + ESP32 펌웨어)과 조종기 펌웨어(Pro Micro 하나로 스틱·스로틀·페달)를 만들었고, 둘 다 컴파일 성공. 컴퓨터 안 시험 30 / 30, PC 쪽 점검 15 / 15 통과.
  • 별도 검토 에이전트가 지적한 진짜 버그 6개(캘리 중 각도 초과로 멈춤, PC 재시작 후 명령 무시 등)를 고치고 시험을 추가했습니다.
  • 실물에서는 아무것도 안 돌려 봤습니다. 가장 먼저 필요한 것: 모터 실제 rpm·토크 확인, 부품 구매 결정.

정한 것 (근거는 각 페이지)

  • 의자 보드: ESP32 DevKitC (I2C 2개로 같은 주소 위치센서 2개), 드라이버 Cytron MDD10A, 기울기 센서 LSM6DSOX, 무게추 위치 AS5600 (풀리 축 끝), 레일 가운데 표시 홀센서.
  • 비상정지는 하드웨어 릴레이가 모터 전원을 직접 끊음. 무게추는 웜기어로 그 자리에 멈춤 → 풀고 시작 버튼 + reset 하면 천천히 수평 복귀.
  • 잠금핀은 "보관함에 꽂혀 있음" 스위치(3개 직렬)로 감지 → 선이 끊겨도 "핀 꽂힘"으로 읽혀 안 움직임.
  • "초기 캘리" = 탈 때마다: 수평 위치 찾기 + "1 mm 당 각도" 재기 → 탑승자 무게가 달라도 맞춤, 낼 수 있는 최대 각도를 PC 에 알림.
  • 조종기: Pro Micro 하나 + TCA9548A 분배기 (서버가 조이스틱 1개만 읽어서). 버튼은 손잡이 안 PCF8574.

사용자 결정 · 구매가 필요한 것

  1. 모터 확인: WGM40C-315724 1/218 의 실제 rpm 과 정격 토크 (필요 12.6 / 16.3 kgf·cm @ 31°) — 판매처 문의. 기울기 속도가 이 값에 그대로 비례.
  2. 더 빨라야 하나? 30T 풀리 (1.7 / 2.4 °/s, 토크 1.5 배) 또는 감속비 약 1/100 (2.5 / 3.5 °/s, 셀프락 확인 필요). 지금 속도도 "지속 가속 느낌" 용도로는 쓸 만함.
  3. 댐퍼 달지: 탑승자가 몸을 3 cm 기울이면 감쇠 없는 가정에서 최고 14° 까지 출렁임. 무게추로는 못 잡음.
  4. 부품 구매: 의자 전자부 약 19.3 만 원 (MDD10A·ESP32 일부 재고 0 표시 → 확인), 조종기 전자부 약 11.7 만 원 (AS5600 6개가 대부분).
  5. 시뮬레이터 cue 변경 (sim 담당): 8 °/s → 0.95 / 1.3 °/s, 씻어내기(washout) 제안은 chair-control.html 1장에. 여기서는 안 고침.

확인 안 된 것

  • 실물 동작 전부 (배선, 센서 방향, 모터 전류, I2C 선 길이 안정성).
  • 가정값: 모터 25 rpm(무부하), 감쇠비 0.03, 탑승자 자체 관성 5 / 4 kg·m², 레일 마찰 0.03, 두 축 서로 영향 없음.
  • 컴퓨터 안 시험은 펌웨어와 같은 식으로 만든 센서 모델을 씀 → 실제 장착 방향 오류는 못 잡음 (대신 캘리 첫 5 mm 에서 방향 검사).
  • pygame 축 번호가 X,Y,Z,Rx,Ry,Rz = 0~5 인지 (처음 꽂고 확인).
  • 부품 가격·재고·자석 포함 여부·릴레이 접점 용량 (조사 에이전트가 페이지를 다 열지 못함).
  • docs/worm.html 이 예전 안(1/28 + 리드스크류)을 추천 중 — index.html 과 다름.
