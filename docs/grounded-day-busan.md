# 밝은 낮에 건물이 떠 보이는 문제 + 실시간 조절 슬라이더 (11-11)

문제: 해가 높은 밝은 낮 (Play 기본 해 42°, 그리고 55–65°) 에도 건물이 땅에 "붙여 넣은" 듯 보임. 사용자 화면 (광안 남천동 아파트, n5) 에서는 아파트의 햇빛 면·그늘 면·지붕이 모두 같은 밝기.
판단 기준은 실제 낮 항공·고층 사진 63장 (`C:\GyroSimTiles\refs\grounded_day\`, 부산 37장 + 도쿄·서울·홍콩·싱가포르 등, `refs.json` 에 출처·라이선스) 에서 렌더와 같은 방법으로 잰 통계. 사진은 git 밖.

## 결론
1. **n5 아파트 명암 없음 = 순광.** 재질 문제 아님. Play 기본 해 방위 215° 가 카메라 방향 40° 의 정반대 (175° 차) 라서 보이는 두 면이 해와 같은 각 (~45°) 을 받음. 실제 사진도 해를 등지면 납작함.
   - 두 면 휘도 (선형): 해 215° 0.475 / 0.464 (0.03 stop). 하늘빛 0.6배 · Lumen GI 끔 · 로컬 노출 1.0 · ArtFix 0 은 모두 0.03–0.07 stop (원인 아님).
   - 해 방위만 255° → 0.578 / 0.231 (1.33 stop), 175° → 0.190 / 0.552 (1.54 stop).
   - 내 조사 시점 21개 중 대부분이 해를 등진 방향 (heading 330–45°) 이었음. 그래서 그림자가 건물 뒤로 숨고 면 대비가 작았음 (측정 편향).
   - 기본 해 방위는 안 바꿈. 어느 방위든 그 반대로 날면 다시 순광이 됨. 대신 슬라이더로 골라 '저장' 하게 함 (아래).
2. **건물 아래쪽이 위보다 어둡지 않음 (가장 큰 차이).** 실사진은 건물 면 아래 10 % 가 가운데보다 L* 8 어둡고, 위 − 아래 차는 11. 렌더는 각각 +1.7 (아래가 더 밝음), 5.1.
   - 고침: 건물 재질에 높이 기반 어둡게 하기를 넣음 (발밑 + 아래→위 기울기, 골목이 트인 곳에도 최소값). 기본값 f3.
   - 같은 실행에서 바꾼 건 이것 하나, 7 시점: 위 − 아래 차 +2.8, 건물 L* −1.5, 사진과의 거리 (IQR 단위) 0.94 → 0.83.
   - 아래 10 % − 가운데 지표는 거의 안 움직임 (+0.25). 낮은 포디움 지붕·사진 속 밝은 바닥이 '건물 아래' 로 잡히는 측정 한계로 **추정**.
3. **Lumen 이 Cesium 건물을 못 보는 것 (가설 a).** 구조상 맞음. 하지만 재질 AO 출력 (하늘빛만 가림) 은 햇빛 받는 화면에서 거의 효과 없음. 화소 차 2.6 이고 같은 설정 반복 차가 2.9.
   - 그래서 AO 는 켜 두되 (그늘에서만 효과, **추정**), 눈에 보이는 고침은 albedo 쪽 (위 2) 임.

변경 끄기: `GYROSIM_GROUNDED_DAY=0` → 이번 작업 전 모습 (건물 GdOn 0, 땅 GdOn 0). 실시간 조절 끄기: `GYROSIM_TUNE=0`.

## 실사진 대비 (조사 렌더 45–48 장, 42°·60°, 순광·옆광·역광 섞임, 같은 자)

| 땅/건물 선명도비 | 1.05 | 1.08 | ~0 |

- 그림자 (d): 모니터 (VSM) 에서 땅 그림자 비율·길이·방향이 사진 범위 안 → 원인 아님.
  - VR (CSM) 렌더도 1.5 km 고도 시점까지 그림자가 있음. 다만 같은 시점에서 그림자 면적이 모니터의 50–70 % (2 시점, 반복 없음 (추정)).
- 채도·밝기 (c): 채도비는 범위 안. 건물 −18 % 어둡게 (ctint) 는 L* −1.6 이지만 아래 − 가운데 지표가 나빠짐 → 채택 안 함.
- 사진에 구워진 그림자 방향 (b): 정사영 시점 4곳에서 사진 그림자 방위를 잼.
  - 해운대 20°, 서면 49°, 중구 328°, 마린시티 320°. 시뮬 그림자는 35–40°.
  - 중구·마린시티는 72–80° 어긋남. 하지만 해를 사진 방위 (140–144°) 로 돌린 렌더 5 시점에서 지표가 일정하게 좋아지지 않음 (오르내림 섞임) → 주원인 아님.
- 그 밖 (e): 렌더 건물이 사진보다 고주파가 적음 (hf_ratio 100 % 가 사진 범위 밖). 사진의 카메라 샤프닝 탓이 섞였을 것으로 **가정**. 땅/건물 선명도 비는 사진과 같음 → '땅만 흐림' 은 아님.

## 가설 실험 (같은 시작점, 한 번에 하나, 구름 고정)
e1 (5 시점), 값은 기준 대비 중앙값 변화. 같은 설정 반복 (base2) 차는 지표 ±0.2, 화소 2.9.

## GPU · 전원
- 상주 렌더 UE: 대기 (1 fps) 28–34 W, 렌더 중 최대 69 W (nvidia-smi, 1회). 렌더 한 장 4 s, 시점 바뀐 첫 장 10–13 s.

## 남은 것
- 최종 전·후 렌더 (낮은 해 b1·b2·g1·a17 회귀 확인 포함) 와 1080p GPU ms 를 아직 못 함.
  - 15:0x 의 fin 실행은 땅 재질이 깨진 상태 (회색 땅) 라 무효.
  - 같은 이유로 `n5_tune_before_sun215.png` / `n5_tune_after_sun255.png` 도 땅이 회색. 건물 면 숫자만 유효함.
  - 다시 찍으려다 나무 작업에 락을 넘김.
- 사용자 고르기 결과로 f2 / f3 / 끔 결정.
- 랜드마크 타워 재질 (M_GyroLandmark) 에는 발밑 어둡게가 없음.
- 아래 10 % − 가운데 지표가 안 움직인 이유 (측정 한계 **추정**) 확인.

## 섞인 변수 · 가정
- 실사진은 대부분 고층 전망대·언덕에서 찍음 (렌더는 150–1500 m 비행 시점). 사진은 카메라 처리를 거침.
- 실사진은 옆광·역광이 많고, 조사 렌더는 순광이 많았음. 해 방향이 섞인 변수.
- 분할은 SegFormer-B2 (ADE20K). 렌더 A/B 는 기준 이미지 한 장의 마스크를 공유함.
- 구름은 바람만 멈춤. 같은 설정 반복 화소 차 2.2–2.9 가 남아 있음.
