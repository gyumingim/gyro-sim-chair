자작 러더 페달 v0 (대강)

러더 = 가운데 축으로 도는 바 (왼발 밀면 오른발이 나옴), 브레이크 = 각 페달 판이 아래 경첩에서 앞으로 꺾임 (발끝). 센서 AS5600 ×3. 바닥은 합판, 러더 바는 알루미늄 프로파일, 페달·받침은 3D 출력. 모델: hardware/pedals/pedals.py. 러더 ±20°, 브레이크 0~15° 조합에서 부품끼리 겹침 없음 (모델 검사).

출력 메모

  • 대강 만든 v0 — 실제 발 크기·각도는 의자에 앉아 맞춰 볼 것 (페달 판 앞으로 20° 기욺).
  • 가운데로 돌아오기: 바 양쪽과 뒤 기둥 사이에 인장 스프링 2 개. 브레이크 복귀: 경첩에 비틀림 스프링.
  • 발로 세게 밟으므로 페달 판·경첩 받침은 PETG, 채움 40 % 이상.
  • 바닥 합판은 의자 페달 레일 위에 볼트로 (앞뒤 조절).
