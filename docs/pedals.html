러더 페달 v3 — 봉 + 볼 부싱 평행 슬라이딩 + 캠 센터링 + 펠트 마찰 (출력 부품 전부 PLA)

결론: v2 와 같은 느낌 (두 페달이 곧게 ±40 mm, 왼발 앞 = 오른발 뒤, 캠 + 롤러 + 스프링 센터링, 토 브레이크 15°), 값은 약 19 만 → 약 9 만 원 (추정, 4040 레일 2 개는 의자 틀 몫). MGN12 레일 → Ø12 연마봉 + LM12UU 볼 부싱, 합판 · 2020 레일 → 의자 4040 바닥 레일 위를 T너트로 미끄러짐, 오일 댐퍼 → 펠트 패드 + 손나사, 알루미늄 캠 → PLA 캠 + 스테인리스 띠.

부품을 누르면 설명이 나옵니다.

주요 값

페달 힘 (계산, 추정)

한쪽 발로 미는 힘. 부싱 · 로드엔드 마찰과 펠트 마찰은 빼고 계산 (v2 와 같은 캠 · 스프링 → 같은 곡선). MIL-F-8785C 페달 이탈력 1~7 lb (4~31 N) 추정, F-15 은 러더 1° 당 43 N 으로 훨씬 무겁다.

어떻게 움직이나

  • 평행 슬라이딩: 페달마다 Ø12 봉 2 개 위에 LM12UU 볼 부싱 4 개 (스틱션 없음). 발 힘이 캐리지를 앞으로 숙이게 하는 힘 (최대 약 180 N·m) 을 봉 2 개 · 부싱 간격 110 mm 가 받는다. 608 바퀴로 4040 위를 굴리는 안은 버림: 발 힘에 뒤 바퀴가 들려 판이 기울어짐 (아래로 잡아 줄 면이 없음).
  • ±40 mm 멈춤: 부싱 상자 끝이 앞틀 · 뒤 받침의 고무 패드에 닿는다 → 한 발 세게 밀어도 힘이 바로 4040 레일로 감 (러더 바 · 축을 안 거침).
  • 러더 바: 알루미늄 평철 30×8 (258 mm) 이 Ø10 축 + 6000 베어링 두 개로 돈다. 양 끝 M6 로드엔드 연결봉 → 캐리지 앞 귀. 러더 상자 옆벽의 창은 바에 닿지 않음.
  • 센터링: 러더 축의 PLA 캠 (롤러 면 4 곳에 스테인리스 띠 0.5 mm) 을 608 롤러 2 개가 누름. 손잡이 너트 = 예압 (이탈력), 스프링 교체 = 기울기. 안 쓸 때 예압을 풀어 두면 캠 · 레버가 덜 눌림.
  • 댐핑: 러더 상자 뚜껑에 붙은 PLA 판스프링 끝의 펠트가 허브 윗테를 누름, 뒤벽 M6 손나사로 세기 조절 (0 = 안 누름). 마찰이라 너무 세면 가운데로 안 돌아옴 (계산: 패드 힘 약 400 N 아래, 추정) — 처음엔 풀어 두고 필요할 때만.
  • 토 브레이크: 페달 판이 발뒤꿈치 Ø8 핀을 중심으로 앞으로 15°. 뒤로 나온 뿔을 압축 스프링이 누르고 M6 나사로 예압. 끝 (15°) 에서 판 뒤 갈비가 캐리지의 멈춤 기둥 2 개에 닿음 → 세게 밟아도 경첩 · 스프링이 아니라 기둥이 받음. 핀 끝 자석 → AS5600.
  • 다리 길이 맞춤: 앞틀 2 + 뒤 받침 2 를 4040 레일 (y ±100) 에 M6 T너트 + 손잡이로 물림. 풀고 밀고, 왼쪽 앞틀의 Ø6 인덱스 핀을 레일 윗면 구멍 (25 mm 간격) 에 꽂음, ±100 mm (키 160~190 cm). 앞틀 ↔ 러더 상자 M5 ×4, 봉이 앞뒤를 묶어서 한 덩어리로 움직임.

출력 후 시험할 것

  • 봉 두 개 평행 (캐리지가 끝에서 끝까지 걸림 없이): 앞틀 · 뒤 받침의 M4 조임을 캐리지를 끝까지 민 상태에서 조인다.
  • 페달 이탈력 · 끝 힘 (러기지 스케일로 발 위치에서), 스프링 · 예압 선택.
  • 펠트 손나사를 조여 가며 발 뗐을 때 가운데로 돌아오는지 (돌아오는 가장 센 자리 표시).
  • 1 주 뒤 캠 띠 들뜸 · PLA 크리프 (가운데 값 변화), 부싱 덜걱거림.
  • 토 브레이크 끝 힘 (목표 30~60 N, 추정) 과 AS5600 범위.
  • 레일 위치 핀으로 160 / 175 / 190 cm 탑승자 무릎 각도 확인.
