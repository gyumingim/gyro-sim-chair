러더 페달 v2 — 평행 슬라이딩 + 캠 센터링 + 오일 댐퍼

결론: MFG Crosswind 처럼 두 페달이 각자 리니어 레일 (MGN12) 위에서 앞뒤로 곧게 미끄러지고, 앞쪽 러더 바가 둘을 묶는다 (왼발 앞 = 오른발 뒤). 가운데 잡기는 스틱과 같은 캠 + 롤러 + 스프링, 흔들림은 RC 카 오일 쇼크로 잡는다 (점성 = 스틱션 없음). 토 브레이크는 발뒤꿈치 경첩 + 스프링 + AS5600.

부품을 누르면 설명이 나옵니다.

주요 값

페달 힘 (계산, 추정)

한쪽 발로 미는 힘. 레일 · 로드엔드 마찰과 오일 댐퍼 (속도에 비례) 는 빼고 계산. MIL-F-8785C 페달 이탈력 1~7 lb (4~31 N) 추정, F-15 은 러더 1° 당 43 N 으로 훨씬 무겁다.

어떻게 움직이나

  • 평행 슬라이딩: 페달이 호를 그리지 않고 곧게 ±40 mm. 조사로는 실기 이동이 F-16 ⅓ in 미만, F/A-18 ±1 in, 기계식 훈련기는 더 큼 → 그 가운데.
  • 러더 바: 알루미늄 평철 30×8 (258 mm) 이 Ø8 축 + 608 두 개 (아래 · 위) 로 돈다. 양 끝 M6 로드엔드 연결봉 → 캐리지 앞 귀. 연결봉 길이로 페달 가운데를 맞춤.
  • 센터링: 러더 축의 알루미늄 캠 (cam_rudder.dxf) 을 롤러 2 개가 누름. 손잡이 너트 = 예압 (이탈력), 스프링 교체 = 기울기.
  • 댐핑: RC 1/8 버기 오일 쇼크 (스프링 뺌) 를 러더 바와 앞 고정점 사이에. 오일 점도 (예: 300~1000 cSt) 로 조절. 너무 진하면 중심으로 늦게 돌아옴 (MFG 댐퍼 0/23 사례).
  • 토 브레이크: 페달 판이 발뒤꿈치 Ø8 핀을 중심으로 앞으로 15°. 뒤로 나온 뿔을 압축 스프링이 위에서 누르고 M6 나사로 예압. 핀 끝 자석 → AS5600.
  • 다리 길이 맞춤: 합판 전체가 의자 바닥의 2020 프로파일 2 줄 위를 미끄러지고 25 mm 간격 핀으로 고정, ±100 mm (키 160~190 cm, 의자 화면에서 확인).

출력 후 시험할 것

  • 레일 두 줄 평행 맞추기 (캐리지가 끝에서 끝까지 걸림 없이) — 합판에 지그로 구멍.
  • 페달 이탈력 · 끝 힘 (러기지 스케일로 발 위치에서), 스프링 · 예압 선택.
  • 오일 쇼크 점도 바꿔가며 가운데 복귀 시간 (발 떼고 1 초 안).
  • 토 브레이크 끝 힘 (목표 30~60 N, 추정) 과 AS5600 범위.
  • 레일 위치 핀으로 160 / 175 / 190 cm 탑승자 무릎 각도 확인.
