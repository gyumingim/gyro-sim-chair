센터 스틱 받침 v2 — 캠 + 롤러 + 스프링 짐벌

결론: VKB · Virpil 고급 받침과 같은 방식. 축마다 알루미늄 캠 + 608 롤러 2 개 + 인장 스프링 1 개로 가운데를 잡아서 미끄럼 마찰 (스틱션) 과 가운데 걸림이 없다. 무게감은 손잡이 너트 (예압) 와 스프링 교체로 조절, 멈춤은 바꿔 끼우는 게이트판.

부품을 누르면 설명이 나옵니다.

주요 값

손에 걸리는 힘 (계산, 추정)

손 위치 = 짐벌 중심에서 mm. 마찰 · 클러치 빼고 캠 모양 + 스프링으로만 계산. 실선 = 기본 스프링, 점선 = 가벼움 / 무거움 교체. 실기 참고: F-15 피치 약 1.4 N/mm, MIL-F-8785C 최소 0.88 N/mm — 실기는 이보다 훨씬 무겁다. 시뮬레이터는 손목 피로 때문에 보통 더 가볍게 쓴다 (무거움 스프링 + 예압 최대로 실기에 가까워짐, 추정).

어떻게 움직이나

  • 짐벌: 바깥 요람 (파랑) = roll, 앞뒤 벽의 608 두 개. 안쪽 블록 (주황) = pitch, 요람 안 608 두 개. 축은 Ø8 h6 연마봉 (볼트 아님 → 덜걱거림 없음), 베어링은 웨이브 와셔로 예압.
  • 가운데 잡기: 캠 모양 r = r0 + a(√(θ²+c²) − c). 가운데가 둥근 V 라서 홈에 '딸깍' 걸리지 않고 또렷한 중심 (c = 2.5°) 다음에 고른 기울기. 롤러 2 개가 맞은편에서 누르니 축에 옆 힘이 안 걸림.
  • 무게감 조절: ① 손잡이 너트 (M5 아이볼트) = 예압 = 이탈력, ② 스프링 3 종 교체 = 기울기, ③ 캠 교체 (DXF 수정) = 느낌 자체 (가운데 없음 / 부드러움).
  • 댐핑: 축마다 건식 마찰 클러치 (PTFE + 마찰 와셔 + 웨이브 스프링 + 나일록). 정지 마찰이 미세 조작을 방해하므로 약하게만 건다.
  • 멈춤: 윗판 = 게이트. TPU 링이 게이트 가장자리에 닿아 부드럽게 멈춤. 기본 roll ±15° (손에서 약 ±110 mm, F-5E 기어 내림 ±4.0 in 과 비슷), pitch 앞 16° / 뒤 20°. 짐벌 자체는 ±20° 까지 겹침 없음.
  • 센서: AS5600 12 bit (0.088°) × 2 → 손에서 약 0.7 mm. roll 은 뒤 축 끝, pitch 는 −y 축 끝.
  • FFB 준비: 앞 축이 벽 밖으로 18 mm (풀리 자리) + M4 ×4 모터 자리, 안쪽 블록 아래에 밀대 고리 (M5). 나중에 모터 2 개를 바닥에 고정하고 밀대로 연결.
  • 손잡이 연결 (hardware/grips): Ø20×2t 관 위 40 mm 가 손잡이 속, 위 끝에서 15 mm 아래 M4 가로볼트, 뒤쪽 4×6 홈 = 돌아감 막기. 배선은 관 속 → 안쪽 블록 아래 구멍.

출력 · 조립 메모

  • 요람 · 안쪽 블록 · 레버 · 게이트판은 PETG, 벽 5 줄, 채움 60~100 %. 나머지 PLA.
  • 캠은 PLA 로 시험 출력 → 느낌이 정해지면 알루미늄 레이저 절단 (hardware/stick/cam_roll.dxf, cam_pitch.dxf). PLA 캠은 롤러 자국이 남음 (접촉 압력 약 50 MPa, 추정).
  • 요람의 roll 캠은 축이 아니라 요람에 M4 ×2 로 고정 (캠 받침 사이에 끼움) → 미끄러져 중심이 어긋나지 않음.
  • 무게 = 부피 × 밀도 × 채움 비율 (추정).

출력 후 시험할 것

  • 가운데 복귀 정밀도: 손 놓고 20 번 → AS5600 값 흩어짐 (목표 ±0.2° 이내).
  • 이탈력 · 끝 힘: 손잡이에 전자 저울 (러기지 스케일) 걸고 1° · 10° · 끝 힘 측정 → 위 그래프와 비교, 스프링 · 예압 정함.
  • 덜걱거림: 가운데서 손잡이를 앞뒤 · 좌우로 흔들어 축 유격 (0.1 mm 다이얼 게이지 또는 센서 값).
  • 멈춤 링이 게이트에 닿는 각도 (계산 roll 15.25°, 앞 16.25°, 뒤 20.25°).
  • 마찰 클러치를 조였을 때 가운데로 돌아오는지 (너무 세면 안 돌아옴 — MFG 페달 댐퍼와 같은 문제).
