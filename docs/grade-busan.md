# 부산 전체 색 보정 (11-10)

목표: 화면 전체 색감 (밝기 분포·대비·화이트밸런스·채도) 을 실제 부산 사진 **여러 장의 통계** 에 맞춘다. 한 장을 눈으로 맞추지 않음.
대기(연무)·해·바다 재질·건물 재질은 다른 작업 몫 — 여기서는 화면 후처리(Post Process)와, 색 보정이 하늘을 망치지 않게 하는 하늘 밝기 계수만.

## 어디에 있나
| 파일 | 하는 일 |
|---|---|
| `unreal/GyroSim/Content/Python/grade_look.py` | 모든 값. `sim_client.apply_look` 끝(`atmos_look` 다음)에서 화질 프리셋마다 적용. 전역 색 보정 키의 유일한 주인 |
| `atmos_look.py` | 11-09 의 채도 ×1.06 / 대비 ×1.08 을 여기서 뺐음 → `grade_look.LEGACY` |
| `Scripts/grade_shots.py` | 두 번째 에디터 화면 밖 전/후 촬영 + GPU (`-GyroSimGradeShots -RenderOffscreen`, 로컬 타일, 결과는 git 밖 `C:\GyroSimTiles\shots\grade`) |

끄기: `GYROSIM_GRADE=0` → 이전 모습 (atmos 의 ×1.06 / ×1.08). `GYROSIM_ATMOS=off` → 맵 원래 값.

## 측정 방법
- 실사진: 위키미디어 공용 (CC BY / BY-SA / PD / KOGL) 92장 + 11-09 세트 11장 (Pexels·Unsplash·공용) = 103장, 사진가 59명.
  대부분 높은 곳·드론·전망대, 일부 지상. 계절·시간·날씨(맑음·연무) 섞임. 목록과 출처·라이선스: `C:\GyroSimTiles\refs\grade\refs.json` (git 밖).
  한 사진가가 많이 올린 경우 1명당 4장까지만 통계에 씀.
- 영역: SegFormer-B2 (ADE20K) 자동 분할로 하늘 / 바다 / 산·숲 / 시가지, 그리고 땅을 화면 위아래로 나눠 먼 곳(위 30 %) / 가까운 곳(아래 40 %).
  실사진과 렌더에 **같은 자** 를 씀.
- 값: CIELAB L* (평균·5/50/95 %), 대비 (L* 표준편차, 95−5 %), 채도 C*, b* (음수 = 푸름), 색상각, 회색 가정 R/G·B/G, 하늘 B/R, 먼 곳−가까운 곳 차이.
- 렌더는 장면 구성이 실사진과 다르다 (바다 비중이 큼) → 화면 전체 값이 아니라 **영역별 값** 으로 맞춤.

## 찾은 차이 (전, 13 장면 중앙값 vs 실사진 90장 중앙값)
검은 곳이 떠 있음 (시가지 L* 하위 5 % 21 vs 13.5), 밝은 곳이 덜 밝음 (상위 5 % 74 vs 85), 대비 낮음 (σL* 15 vs 21),
땅이 푸르스름 (시가지 b* −8 vs 0, 회색 가정 R/G 0.75 vs 0.84). 채도는 낮지 않았음 (시가지 C* 12 vs 9.5) → "물빠짐" 은 채도가 아니라 검정·대비·푸른 기운.

## 값 (`grade_look.GRADE`) 과 이유
| 키 | 값 | 이유 |
|---|---|---|
| `film_toe` / `film_slope` | 0.6 / 1.0 (엔진 0.55 / 0.88) | 검정 깊게, S 곡선. 0.65 는 낮은 시가지 장면 그늘을 L* 1–4 로 뭉갬 |
| `color_contrast` | 1.2 (전 1.08) | 1.3 은 그늘 뭉갬 |
| `white_temp` | 6900 K | 7500 K 는 땅은 맞지만 하늘이 회색 (b* −8.7 → −3.5) |
| `color_gain_shadows` / `_midtones` | (1.05, 1.0, 0.92) | 땅(어둡고 중간 밝기)만 따뜻하게, 하늘(밝은 영역)은 그대로 |
| `auto_exposure_bias` | 0.35 (맵 0.3) | 하늘 계수가 하늘빛을 밝게 하므로 조금만 |
| `color_saturation` | 0.88 (전 1.06) | S 곡선이 채도를 올림 → 건물 C* 를 실사진 쪽으로 |
| `sky.sky_luminance_factor` | (0.42, 0.72, 1.35) (realism v2 0.80/0.86/1.0) | 따뜻한 보정으로 회색이 되는 하늘을 되돌림. 빼면 하늘 b* +0.9 (회색) |
비네트·블룸·국소 노출은 그대로 (조종석용 값, `sim_client.PRESET_LOOK` / realism v2).

## 남은 것
- 하늘이 실사진보다 덜 파람 (구름 많음, 연무 흰색 — 대기 쪽 문제), 바다 진함 (바다 재질), 산·숲 밝음 (나무·사진 재질).
- 값은 이 13 장면으로 고르고 같은 장면으로 채점 (따로 떼어 둔 검증 장면 없음). 구름이 실행마다 달라 하늘 수치가 흔들림 (전 기준 b* −8.7 ~ −12.8) → 같은 실행 안의 전/후만 비교.
- VR 은 같은 값 (따로 촬영 안 함).

## 가정 (확인 안 된 것)
- 실사진 13장은 Adobe RGB 등 sRGB 가 아닌 색공간인데 sRGB 로 읽었다 → 실사진 채도 목표가 약간 낮게 잡혔을 수 있음 (추정).
- 목표 = "보통 실사진의 모습" 이다. 실사진은 카메라·폰 처리(HDR, 채도·대비 올림, 샤픈, 자동 화이트밸런스)를 이미 거쳤다. 눈으로 본 실제 풍경과 같다는 뜻이 아니다.
- 전/후 장면 위치는 사진 위치 추정이며, 실사진과 같은 날씨·시간이 아니다 — 장면별 비교는 참고용, 판단은 전체 통계로.
- 먼/가까운 구분은 화면 높이로 근사 (내려다보는 장면에서는 약함).
