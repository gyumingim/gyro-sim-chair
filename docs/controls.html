비행 시뮬레이터 조종기 종류

무엇을 조종하느냐에 따라 고르면 된다. 전투기 → HOTAS + 페달, 여객기·경비행기 → 요크 (또는 사이드스틱) + 스로틀 쿼드런트 + 페달. 가격은 대략 (추정).

이 의자에 맞는 조합

전투기 위주

HOTAS + 러더 페달. 스틱은 다리 사이 (바닥 받침), 스로틀은 왼쪽 레일 안쪽.

약 25~35만 원 (T.Flight HOTAS 4 + TFRP, 추정)

여객기·경비행기 위주

요크 + 스로틀 쿼드런트 + 러더 페달. 요크는 모니터 아래 앞 가로대에 고정.

약 40~70만 원 (추정)

일단 싸게

조이스틱 하나 (비틀면 러더). 나중에 페달 추가.

약 5~10만 원

직접 만들기

Arduino Pro Micro + AS5600 홀 센서 + PLA 짐벌. 버튼 박스 → 트림 휠 → 스로틀 → 페달 → 스틱 순서로 쉬움.

한 개당 1~2만 원대 (추정)
