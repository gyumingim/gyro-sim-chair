시뮬레이터 운영 안내

시뮬레이터를 켜고 훈련생을 앉히는 사람을 위한 글이에요. 훈련생용 설명서는 비행 훈련 설명서.

1. 켜기 (순서대로)

  1. 비행 서버: sim 폴더에서 
    set PYTHONIOENCODING=utf-8
python server.py
    비행 계산(JSBSim F-16, 120 Hz), 교관(강의 · 음성), 의자 명령을 맡아요. 브라우저 화면 http://127.0.0.1:8780/.
  2. 언리얼: unreal/GyroSim/GyroSim.uproject 열기 → Play. VR 은 Play 옆 ▾ → VR Preview (헤드셋을 먼저 켜 두기).
  3. 화면 가운데 훈련 화면에 메뉴가 뜨면 준비 끝. 훈련생 이름은 메뉴 → 훈련생 에서 고르거나 새로 만들어요.

필요한 것: Python 3 + pip install jsbsim websockets pygame pillow psutil, Unreal Engine 5.8. 교관 음성은 Windows 한국어 음성(Heami)을 써요. 없으면 글씨만 나와요.

2. 입력 장치

장치설정
키보드그대로. 언리얼 창이 앞에 있어야 해요.
조이스틱 · 스로틀 · 페달 (USB)sim/controls.json 의 축 번호. 꽂혀 있으면 키보드보다 우선. 버튼: "buttons" 항목 (기본 0 = 선택/다음, 1 = 뒤로, 2 = 다시 듣기, 3 = 메뉴).
교관 말투자동: VR 헤드셋이나 조이스틱이 있으면 “오른손으로 스틱을…”, 아니면 “↓ 키를…”. 훈련생이 I 로 바꿀 수 있어요.

3. 의자

서버가 기체 자세와 가속에서 의자 명령을 만들어 UDP 127.0.0.1:4210 으로 보내요({"roll":..,"pitch":..}, 도). 한계는 실제 의자 값: 좌우 ±18°, 앞뒤 ±14°, 최대 속도 좌우 1.3 °/s · 앞뒤 0.95 °/s, 가속 0.6 / 0.48 °/s², 0.5 s 저역 통과. 오른쪽 화면(의자 · 경고)에 지금 각도와 한계가 보여요.

의자 제어기 쪽(control/, firmware/)은 다른 문서에서 다뤄요.

4. 훈련생 관리

  • 기록: sim/profiles/<이름>.json (강의별 최고 점수, 통과 횟수, 최근 20 번 기록, 음성·쉬운 모드 설정). git 에 올라가지 않아요.
  • 처음 타는 사람: 0 번부터. 쉬운 모드는 ‘자동’(처음 두 번 시도만 켬)이 기본.
  • 멀미하면 P(멈춤). 의자도 그 자리에서 멈춰요.
  • 강의를 강제로 끝내려면 F1 → 메뉴. R / T 는 강의 중에 두 번 눌러야 해요.

5. 문제가 생기면

증상할 일
훈련 화면이 “waiting for sim/server.py”서버가 꺼졌어요. 다시 켜면 언리얼은 저절로 다시 붙어요(재시작 시험: 끊김 후 수 초 안에 메뉴로 돌아옴).
교관 목소리가 안 나와요Y 로 켜져 있는지, 메뉴 → 설정 → 음량. Windows 한국어 음성 팩이 있는지.
조이스틱이 안 먹어요서버를 켜기 전에 꽂기. sim/controls.json 축 번호 확인.
VR 에서 화면이 기울어 보여요F3 정면 맞추기.
화면이 끊겨요언리얼 콘솔 stat unit. 이 PC 기준 GPU 약 3.8 ms (1080p), VR 두 눈 픽셀 수 기준 약 5.0 ms (구름 포함, 추정 — 실제 헤드셋 측정 아님).
