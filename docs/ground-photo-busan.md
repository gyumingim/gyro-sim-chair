# 땅 사진 (V-World 정사영상) 밝기 조절 (11-11)

문제: 땅에 깔린 V-World 정사영상이 한낮 측량 사진처럼 밝아 보임. 사용자 제안: 밝기를 낮추면 더 자연스러울 것.
처리는 렌더할 때 셰이더 안에서만 함. 사진 파일을 바꾸거나 저장하지 않음 (V-World 약관: 가공한 영상 저장 금지).

## 결론
- 기본값: **땅 사진 밝기 x0.9** (`PhGain 0.9`). 감마·채도·밝은 곳 누르기는 1 (끔). 슬라이더로만 조절함.
- 근거 (아래 표): 렌더 땅의 L*50·L*90 이 실사진 60장 중앙값보다 높음. x0.9 로 중앙값 쪽으로 감.
  - 땅 − 건물 L* 차는 x0.9 에서도 2 / 3 시점이 실사진 IQR 안. x0.85·x0.75 는 IQR 밖으로 나감 (땅이 건물보다 너무 어두워짐).
  - 종합 거리 (IQR 단위, 6 지표 평균) 는 지금 0.29, x0.9 0.31, x0.85 0.34, x0.75 0.36. 차이가 작고, 한 번씩만 렌더함 (반복 없음). 그래서 x0.9 의 이득은 **추정**.
- 더 큰 차이는 **화면 전체 밝기**. 렌더 건물 L*50 이 51–62 로 실사진 48 보다 높음. 땅 사진만 어둡게 하면 땅/건물 균형이 나빠짐.
  - 그래서 땅만 많이 낮추지 않음. 전체가 밝다면 노출 보정 (`exposure_bias`) 쪽이 맞을 것으로 **추정** (이번에 안 바꿈).
- 채도: 렌더 땅 C*50 7.6–11.4, 실사진 10.1 [7.5, 11.6] → 범위 안. 안 바꿈.
- 밝은 곳 날아감: 렌더 땅 중 L* > 85 비율 0.00–0.01 (실사진 0.01) → 지금 시점들에선 없음. 누르기 (knee) 는 슬라이더로만 둠.
- 사용자 고르기 페이지 (블라인드, 3 시점 × x0.9 / x0.85 / x0.75 대 지금): http://127.0.0.1:8767/today/busan_ground_bright/ (답 키는 페이지 폴더 밖).
- GPU (n5, 776×550 × 220 % ≈ 1707×1210, 10 s, 1회): 지금 4.50 ms, 변형들 4.51–4.53 ms → 차이 없음 (잡음 수준).

변경 끄기: `GYROSIM_GROUND_PHOTO_V2=0` → 이번 작업 전 모습 (PhGain/PhGamma/PhSat/PhKnee 모두 1). 슬라이더 값보다 우선.

## 섞인 변수 · 가정
- 실사진은 대부분 고층 전망대·언덕에서 찍은 사진이고 카메라 처리를 거침. 렌더는 150–500 m 비행 시점.
- 실사진의 '땅' 은 SegFormer 분할 (나무·도로·공터 포함), 렌더의 '땅' 은 V-World 사진 화소 (3D 나무·건물 제외). 같은 것이 아님.
- 렌더 시 실시간 조절 끔 (`GYROSIM_TUNE=0`) → 로컬 노출 0.85 등 tune_defaults 값 대신 각 모듈 기본값. 모든 변형이 같은 조건.
- 한 장씩, 반복 없음 (사용자 결정). 앞선 작업의 같은 설정 반복 차는 지표 ±0.2 (IQR 단위) 정도였음 → 이번 변형 간 차 (≤ 0.07) 보다 큼.
