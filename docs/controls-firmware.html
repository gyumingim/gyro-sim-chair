조종기 펌웨어 — 스틱 · 스로틀 · 페달을 USB 조이스틱 하나로

2026-11-05. 코드: firmware/controls/ (PlatformIO). 기구: 스틱 · 스로틀 · 페달.

기구 v2 (2026-11-05): 센서 배치는 그대로 (AS5600 6 개, 채널 0~5 같음). 스로틀의 컷오프 · 아이들 · MIL · AB 는 따로 스위치 없이 각도로 판별 — 모델 기준 컷오프 ≤ −31°, 아이들 −25°, MIL 18°, AB ≥ 27° (CAL 로 실물 각도 다시 잼). 스틱은 짐벌 ±20° 중 게이트가 roll ±10° · pitch +10/−13° 만 쓰므로 CAL 의 끝값이 게이트 기준.

결론
  • 보드 하나 (아두이노 Pro Micro, 스틱 받침 안). 시뮬레이터(sim/server.py)가 조이스틱을 하나만 읽기 때문 — sim/controls.json 의 축 0 = 에일러론, 1 = 엘리베이터, 2 = 스로틀, 3 = 러더 그대로 맞춤.
  • AS5600 6개가 주소가 모두 같음(0x36) → TCA9548A I2C 분배기로 해결. 12비트(0.088°) 그대로 쓰고, 자석 빠짐도 감지. 페달까지 긴 선이 다른 센서 버스에 영향을 안 줌.
  • 버튼·햇은 손잡이 안 PCF8574 에 연결 → 스틱·스로틀까지 선이 4가닥(전원 2 + I2C 2)뿐.
  • 캘리 모드(버튼 2초)로 가운데·끝값을 EEPROM 에 저장, 데드존 가운데 2 % · 끝 1 %. 컴파일 성공 (Flash 61 %, RAM 33 %). 실물 시험 안 함.

2. 왜 이렇게 골랐나

질문선택이유
보드 하나 vs 셋하나서버가 조이스틱 1개(joystick_index)만 읽음. 셋으로 나누면 서버를 고쳐야 함. USB 선도 하나.
같은 주소 AS5600 6개TCA9548A 분배기아날로그 OUT 은 Pro Micro 10비트 ADC 로 360° 를 나눠 0.35° 단위 — 스틱 ±20° 에 115 단계뿐이라 거침. 소프트웨어 I2C 는 핀이 모자람. 분배기는 채널마다 버스가 따로라 긴 페달 선의 정전용량이 다른 센서에 안 걸림.
버튼 15개 + 햇PCF8574 2개 (손잡이 안)Pro Micro 핀 18개로 직접 배선하면 빠듯하고, 움직이는 스틱 안으로 선 10가닥 이상이 지나가야 함 → 4가닥으로 줄임.
I2C 속도100 kHz페달까지 약 1.5 m. 모든 선이 짧으면 400 kHz 로 올려도 됨 (Wire.setClock).

4. 캘리브레이션

  1. 캘리 버튼을 2초 누름 (또는 USB 시리얼 115200 에 cal) → LED 빠르게 깜빡임.
  2. 다 놓기: 스틱은 스프링으로 가운데, 페달 가운데, 스로틀 아이들(뒤), 브레이크 놓음 → 버튼 짧게 (또는 next). 32번 평균해 기준점 저장.
  3. 모든 축을 양 끝까지 2~3번 (스틱은 원 그리기, 스로틀 아이들↔최대, 러더 양쪽, 브레이크 각각 끝까지) → 버튼 짧게.
  4. 축마다 움직임이 100 단계(약 9°) 이상이고 가운데 축은 양쪽 다 움직였으면 EEPROM 에 저장 (LED 켜짐). 아니면 이전 값 유지하고 어느 축이 모자란지 시리얼에 출력.
  • 데드존: 가운데 2 %, 끝 1 % (시리얼 dz 0~20 로 가운데 값 변경). 서버에도 0.03 데드존이 있어 겹침 — 필요하면 서버 쪽을 0 으로.
  • 센서 고장(자석 없음, 응답 없음)이면 그 축은 천천히 가운데(브레이크·스로틀은 놓은 쪽)로 가고 LED 가 천천히 깜빡임.
  • 시리얼 명령: cal, next, dump (원값·캘리값·출력), raw (원값 계속 출력), dz N, reset (기본값).
  • 0 / 4095 경계를 넘는 센서 위치도 처리 (기준점에서 ±180° 로 계산).

6. 확인 안 된 것

  • pygame 이 Windows 에서 축을 X, Y, Z, Rx, Ry, Rz 순서로 0~5 번에 매기는지 — 처음 꽂고 서버 화면이나 joy.cpl 로 확인. 다르면 controls.json 의 번호만 바꾸면 됨.
  • 100 kHz I2C 가 페달 1.5 m 선에서 안정한지 (차폐선 권장). 문제면 페달만 별도 Pro Micro 로 나누는 방법도 있으나 그러면 서버 수정 필요.
  • AS5600 보드의 전원 전압 (Adafruit 는 3~5 V 가능으로 알려짐 — 받아서 확인).
  • 발끝 브레이크 축(Ry/Rz)은 서버가 아직 안 읽음. 쓰려면 서버에서 (1 + v)/2 로 0~1 변환 필요.
  • 실물 납땜·시험 안 함. 컴파일만 확인 (python -m platformio run -d firmware/controls).
