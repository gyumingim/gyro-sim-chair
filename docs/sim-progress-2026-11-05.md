# 시뮬레이터 · 튜토리얼 밤 작업 정리 (2026-11-04 → 11-05)

## 결론
- 강의 0~10 이 처음부터 끝까지 동작한다. 흐름은 브리핑 → 시범(자동 조종이 조종 장치를 움직임) → 연습(교관 코칭·음성) → 단독 점검 → 결과.
  - 메뉴는 키보드로도, 스틱 + 버튼으로도 조작된다.
  - 훈련생 기록을 저장한다. 쉬운 모드와 느린 시간이 있고, 사고가 나면 이유를 설명한 뒤 바로 다시 할 수 있다.

- 조종석 v2는 장식을 걷어냈다. 실제 값을 보여 주는 큰 화면 3 개, 상태등 6 개, 예비 계기 4 개(실시간 바늘)가 남는다.
- 땅은 사용자 결정대로 **격자가 기본**이다. 리뷰가 제안한 들판 모습은 선택 모드(`Config/cesium_token.txt` 에 `fields` 한 줄)로만 넣었다. 적운 구름을 넣었다.
- 점검 결과:
  - 언리얼 Play 자동 점검 30/30 통과 (마지막 00:44, 격자 땅).
  - 학생 봇 3 종(잘함·서툼·반대로) × 강의 11 개 × 쉬운 모드 켬/끔 = 66/66 통과.
  - 켜진 서버 대상 시험 통과.
  - 1 시간 soak 통과 (아래).

## 남은 약점 (정직하게)
- VR 헤드셋 실기 시험을 하지 않았다. 손 위치(RIG_EYE)는 추정이고, VR 프레임 시간도 추정이다.
- 진짜 초보자가 해 본 적이 없다. 강의 조건값은 학생 봇으로만 맞췄다.
- 학생 봇의 단독 점검에서 시간 안에 끝난 단계가 범위 안 시간이 0 이어도 60 점을 받는다(예전 규칙). 착륙 강하 1 단계에서 드러난다.
- HUD 글자에 그림자가 없어 밝은 구름 앞에서 덜 보인다. 피치 사다리가 속도·고도 상자 뒤로 지나간다(가리지 않음).
- 화면 리뷰 항목 중 남은 것:
  - 초보자 설명 큰 글씨 겹침 일부.
  - 계기판 'WHEELS' 이름표가 왼쪽 화면 아래에 일부 가려진다.
  - 기어 손잡이 이름표가 손잡이에 가려진다.
  - 콘솔의 흰 선.
  - 구름 탑(높이) 표현.
  - verify 6a/6b/7 카메라 이름이 맞지 않는다.
- 브라우저 화면의 리셋 버튼은 확인 없이 바로 리셋한다. 강의 중 M(처음부터)과 0~9(다른 강의)는 한 번 누르면 바로 된다.
- 위성사진(`photo`) 땅 모드는 이번에 타일이 보이지 않았다. 원인은 조사하지 않았고, 기본 모드가 아니다.

## 사용자 결정이 필요한 리뷰 제안
- 기본 땅: 격자(지금, 사용자 결정) 대 들판(`fields`, 리뷰 제안 — 하늘에서 격자가 "디버그처럼" 보인다는 지적). 바꾸려면 설정 한 줄.
