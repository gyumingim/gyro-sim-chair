# 언리얼 5.8 화면 (GyroSim)

비행 계산은 그대로 `sim/server.py` (JSBSim F-16). 언리얼은 **화면만** 그린다. C++ 없음 (Visual Studio 없어도 됨), 에디터 Python 으로 동작.
모니터와 VR 둘 다 된다. 시작 위치 = **청주 기지(RKTU) 활주로 06R** (실제 좌표·방향 052°, 표고 191 ft).
설명서: `docs/sim-tutorial.html` (서버 켜면 http://127.0.0.1:8780/docs/sim-tutorial.html). 외부 자료 출처·라이선스: `GyroSim/ATTRIBUTION.md`.

## 처음 한 번 (설치)
git 에는 스크립트만 있다. 큰 파일·외부 자료는 각자 받는다 (모두 .gitignore).
```
powershell -ExecutionPolicy Bypass -File unreal\GyroSim\Scripts\install_cesium.ps1   # Cesium for Unreal 2.31 (UE 5.8, 약 1.3 GB 받음)
python unreal\GyroSim\Scripts\fetch_f16_model.py                                     # FlightGear F-16 모델 → OBJ (GPL-2.0, 약 30 MB)
python unreal\GyroSim\Scripts\fetch_textures.py                                      # Poly Haven 사진 텍스처 (CC0)
"C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" unreal\GyroSim\GyroSim.uproject -run=pythonscript -script=<전체경로>\unreal\GyroSim\Scripts\build_level.py -unattended -nosplash -nullrhi
```
(마지막 줄 = 맵 다시 만들기. 에디터를 닫고 돌린다 — 열린 에디터 안에서 돌리면 맵을 다시 읽다가 에디터가 죽은 적 있음.)

## 땅 모드 (기본 = 격자)
기본은 **격자 땅** (사용자 결정 "땅 사진 아직 말고 그냥 격자 맵으로"): 표고 191 ft 의 평평한 땅 (지구 곡률을 따라 휨, 반경 300 km, 지평선까지), 100 m 마다 옅은 선·1 km 마다 진한 선.
멀어지면 선이 자연스럽게 흐려져 무늬 떨림이 없다. 아무것도 내려받지 않음 (타일 스트리밍 없음). 활주로·유도로·풀 텍스처는 그대로.
다른 모드는 `unreal/GyroSim/Config/cesium_token.txt` (git 제외) 에 한 줄로 적어서 고른다:
| 줄 | 땅 |
|---|---|
| (파일 없음) 또는 `grid` | 격자 (기본) |
| `fields` | 같은 평평한 땅에 재질로 그린 시골 들판 (논밭 조각 · 고랑 · 밭둑 · 숲 · 마을, 텍스처·내려받기 없음, 선택 사항 — `M_Countryside`) |
| `photo` | 평평한 땅 + 위성사진 (Sentinel-2, 10 m 해상도, 인터넷으로 받음 — 처음엔 타일이 하나씩 채워짐) |
| 토큰 한 줄 | Cesium World Terrain (실제 산) + Bing 항공사진 |
| 토큰 + `photoreal` | Google 사실적 3D 타일 (더 무거움) |

### 실제 지형 켜기 — Cesium ion 토큰 (나중에 원하면, 사용자가 할 일)
1. https://ion.cesium.com 에서 무료 가입 (Community 요금제, 카드 필요 없음).
2. 로그인 후 위 메뉴 **Access Tokens** → **Create token** → 이름 아무거나, 권한은 기본값(assets:read) 그대로 → Create.
   (기본으로 있는 "Default" 토큰을 써도 된다.)
3. 토큰 문자열(eyJ… 로 시작하는 긴 글자)을 복사해서 새 텍스트 파일 `unreal/GyroSim/Config/cesium_token.txt` 의 **첫 줄**에 붙여 넣고 저장.
   (git 에 안 올라가게 막아 둠. 둘째 줄에 `photoreal` 이라고 쓰면 Google 사실적 3D 타일 — 더 무겁다. `grid` 줄을 더하면 토큰이 있어도 격자.)
4. Play 를 다시 누른다. 토큰이 틀렸거나 인터넷이 안 되면 20 초 뒤 자동으로 격자 땅으로 돌아가고 HUD 에 "CESIUM TERRAIN FAILED" 가 뜸.

## 실행
1. `python sim/server.py` (브라우저 http://127.0.0.1:8780/ 은 계속 됨 — 교관/강의 화면으로 쓰기)
2. `unreal/GyroSim/GyroSim.uproject` 더블클릭 (UE 5.8). 처음 열 때 셰이더 컴파일로 몇 분 걸릴 수 있음.
3. **모니터**: 위쪽 **Play** (▶) → **새 창**으로 열리고 화면 크기로 커짐. **F11** = 전체 화면. **VR**: Play 옆 ▾ → **VR Preview**. 끝내기는 Esc.
   Play 를 누를 때마다 **항상 공중 시작 (6000 ft, 350 kt) 부터 새로** 시작한다 (서버는 언리얼이 꺼져 있어도 계속 날고 있어서, 예전엔 엉뚱한 곳·엉뚱한 시각에서 시작했음).
   화면이 다 뜨고 fps 가 돌아올 때까지 (보통 1.5 초) 서버를 일시정지해 두고 HUD 에 "LOADING - SIM PAUSED" 를 보여 준 뒤 풀어 준다 (최대 15 초).

## 조종 (언리얼 창이 앞에 있을 때)
| 키 | 동작 |
|---|---|
| ← → / ↑ ↓ | 스틱 좌우 / 밀기·당기기 (↓ = 당기기). 누르고 있으면 천천히 끝까지, 놓으면 가운데로 |
| A D / W S / B / G | 러더 페달 / 스로틀 / 브레이크 / 바퀴 올림·내림 |
| R / T | 공중 시작 (6000 ft, 350 kt, 방위 000) / 활주로 06R 시작. 강의 중에는 4 초 안에 두 번 (강의를 끝내고 자유 비행) |
| V | 조종석 ↔ 뒤쪽 추적 시점 |
| C / Q E | (모니터) 아래 보기 / 왼쪽·오른쪽 보기 |
| P | 일시정지 |
| **H** | 강의판 켜기/끄기 (떠 있는 작은 판 — **VR 에서만**. 모니터에선 가운데 훈련 화면이 같은 그림) |
| **K** | 키 안내판 (메뉴에서는 항상, 비행 중엔 K 로 켬. 그림 = `sim/key_panel.png`, 고치면 `python sim/key_panel.py`) |
| **U** | HUD 켜기/끄기 |
| F1 / F2 | 메뉴 (↑↓ Enter Backspace, 닫으면 강의로 돌아감) / 강의 끝 |
| 0~9, N, M | 강의 시작, 다음 (단독 점검 건너뛰기는 두 번), 다시 |
| Z / Y / L / I | 교관 말 다시 듣기 / 음성 켜기·끄기 / 초보자 한국어 이름표 켜기·끄기 (기본 켬) / 안내 말투 자동→키보드→조종 장치 |
| F3 / F9 / F11 | VR 정면 다시 맞추기 / VR 스테레오 켜기·끄기 / 전체 화면 |
| (추락 화면) | **Enter · R · N · 마우스로 '다시하기'** = 같은 단계(자유 비행이면 같은 시작점)부터 다시, **F1 · 마우스로 '메뉴'** = 메뉴. 조이스틱: 트리거 = 다시하기, 두 번째 버튼 = 메뉴. 추락 뒤 1 초 동안은 입력을 무시 |

### 추락 화면 (11-05)
땅에 세게 닿거나(강하율 1500 ft/분 넘게), 기운 채(25° 넘게), 바퀴를 안 내리고 닿거나, 땅에 부딪히면 시뮬레이터가 멈추고 **빨간 화면**이 뜬다
(강의 중이든 자유 비행이든). 큰 글씨 "추락" + 이유 한 줄(예: "너무 빠르게 내려옴 -2400 ft/분") + 버튼 2 개(다시하기 / 메뉴).
그림은 서버가 그림 (`sim/training/render.py`), 언리얼은 시점 카메라에 붙은 판 2 장(`CrashBack`, `CrashPanel`, 150 cm 앞, 깊이 무시)으로 보여 줌 —
모니터·VR 모두 (VR 에선 머리를 따라옴, 깜박임 없음). 브라우저 화면도 같은 빨간 화면과 누를 수 있는 버튼.
강의 중 판정(활주로 이탈, G 초과, 공중 강의에서 너무 낮음)은 강의에서만, 자유 비행은 땅에 닿는 것만 추락으로 본다.

조이스틱이 꽂혀 있으면 그 축이 먼저 (`sim/controls.json`). 우선순위: 조이스틱 > 언리얼 키보드 > 브라우저.

## 무엇이 어떻게
```
sim/server.py (JSBSim 120 Hz) ─ UDP 4220, 60 Hz 상태 JSON → 언리얼 (Content/Python/sim_client.py)
        ↑ └ UDP 4221 조종/명령 JSON  ←───────────────────────────────────────────┘
        ├─ sim/airfield.py : 청주 활주로 좌표·표고·지오이드 (서버·언리얼 공용)
        ├─ sim/training/ : 교관 (강의 0~10, 메뉴, 시범 자동 조종, 코칭, 점수, 훈련생 기록) + 한글 훈련 화면 PNG → 가운데 화면·HUD 한 줄
        ├─ sim/voice.py : 교관 음성 (Windows SAPI 한국어, 따로 도는 PowerShell, 막히지 않음)
        └─ WebSocket 8781 / HTTP 8780 : 브라우저 화면, UDP 4210 : 의자 명령
```
- **좌표**: 시작점(활주로 06R 문턱에서 150 m) = 원점, X 북 / Y 동 / Z 위, WGS84 타원체 기준 정확한 접평면 (`geo.py`) = Cesium 좌표계를 90° 돌린 것.
  그래서 기체·활주로·Cesium 지구가 같은 곡률 위에 있다 (50 km 가면 땅이 196 m 내려감). JSBSim 고도 + 지오이드 25.08 m = Cesium 높이.
- **기체 겉모습**: FlightGear F-16 (GPL-2.0, 추적 시점용, git 에 없음). **조종석 안은 우리가 직접 만든 것** (아래 "조종석").
- **HUD** (`hud.py`): 초록 전투기식 — 피치 사다리(5° 간격, 아래쪽 점선), 수평선, 비행경로 표시(FPM, 받음각·옆미끄럼으로), 보어사이트, 방위 테이프(아래), 속도·고도 상자,
  G, 마하, AOA, 수직속도, 전파고도(R), 스로틀, 기어, 브레이크, 강의 한 줄, 경고(PULL UP / TERRAIN).
  조종석 앞 20 m 에 놓인 판에 그리고 깊이 검사 없이 TSR 뒤에 합성 → 번짐 없음, 바깥 세상과 각도가 맞음 (콜리메이트), VR 에서도 보임.
  피치 사다리는 한 번 그려 둔 그림을 재질이 매 프레임 롤·피치로 찾아 그림 (Python 부담 없음). 글자·테이프·FPM 은 30 Hz.
- **계기판 화면 3 개** (`hud.py`): 가운데 = 훈련 화면 (서버가 그린 한글 그림 + 목표 막대 + 최근 30 초 차이 그래프), 왼쪽 = 비행 정보 (큰 숫자 칸, 초록/노랑/빨강),
  오른쪽 = 의자 각도 대 한계 (±18° / ±14°, 최대 속도) + 경고 목록 (PULL UP · TERRAIN · OVER-G · STALL · GEAR) + 상태 (멈춤 · 시범 · 쉬운 모드 · 느린 시간).
  초보자 모드에서는 모든 이름표가 한글 그림 (`Scripts/cockpit/make_labels.py` 아틀라스 — 캔버스 글꼴에 한글이 없어서). 계기판 위 WARNING 등 (빨강 경고에 깜박임), MASTER CAUTION (경고가 있으면 켜짐).
- **활주로**: 06R/24L(45 m), 06L/24R(60 m) 두 개를 실제 좌표에 콘크리트 사진 텍스처로, 표시선(문턱, 중심선, 조준점, 접지구역, 번호). 지구 곡률을 따라 휨.
- **부드러운 움직임**: 패킷 sim 시간으로 보간 (점검: 보간 켬 = 프레임당 이동 변동계수 0.18, 끔 = 1.0 / 절반 프레임 멈춤).
- **화질 설정** (`sim_client.apply_preset`): 모니터 = Lumen·VSM·TSR·볼류메트릭 구름, VR = Lumen 끔·TAA 등 (헤드셋 켜지면 자동).

## 점검 도구 (server.py 켠 상태에서)
- `UnrealEditor.exe GyroSim.uproject -GyroSimVerify` : 45 초 뒤 Play → 위치·자세 부호, 조종 장치 각도, 예비 계기 바늘·ADI·기어 손잡이·바퀴 등, 강의판(모니터에선 숨김), 키 안내판·K 토글, HUD 그림 수, 보간 매끄러움, 추락 빨간 화면 → 1 초 입력 잠금 → 버튼 클릭 위치 → 다시하기 →
  스크린샷·`verify_result.json` 을 `Saved/verify/` 에 저장 → Play 종료.
- `Scripts/measure_fps.py` : GPU 시간 측정 → `Saved/verify/fps_<이름>.json`. `Scripts/keyboard_test.py` : 키 입력 경로 점검.

## 조종석 (우리 모델, 라이선스 깨끗 — git 에 들어 있음)
T-50 / F/A-18 식 훈련기 배치: **가운데 스틱, 왼쪽 스로틀, 발끝 브레이크 페달** = 실제 의자와 같은 자리 (눈 기준, VR 에서 손이 맞게).
- 위치 근거: `index.html` 의자 모델 + `hardware/stick·throttle·pedals`. 눈 위치는 **추정** (`Scripts/cockpit/layout.py` 의 `RIG_EYE`, 머리 구 중심 + 앞 8 cm). 실측하면 그 값만 고치고 다시 만든다.
  스틱 피벗 = 눈 앞 34.5 cm·아래 65 cm, ±20° / 스로틀 = 왼쪽 32 cm, ±30° / 페달 = ±13.5 cm, 앞뒤 ±4.6 cm (러더 바 ±20°), 발끝 브레이크 15°.
  바닥·페달 높이는 F-16 동체 안에 넣으려고 실제보다 약 4 cm 높다 (`floor_z`).
- 구성 (v2, 11-04: 장식 걷어냄): 사출좌석, 캐노피 틀·뒤 아치 (앞 바우 없음), 글레어 실드, HUD 결합 유리 (위 끝 약 +8° — HUD 글자가 유리 위에, 얇은 기둥),
  큰 화면 3 개 (실제 값), 예비 계기 **ADI 볼·속도계·고도계(바늘 2 개)·승강계 = 실시간 바늘**, 상태등 6 개 (MASTER CAUTION · WARNING · 브레이크 · 쉬운 모드 · 느린 시간 · 음성),
  기어 손잡이 (명령 따라 움직임) + 바퀴 3 등, 스로틀 쿼드런트. 가짜 스위치·키패드·고정 계기·거울은 없앰.
- 만드는 법 (모두 스크립트, 손으로 만든 것 없음):
```
python unreal\GyroSim\Scripts\cockpit\build_cockpit.py      # PIL 텍스처 + Blender 4.5 (포터블 zip 가능) → Art/Cockpit/*.fbx, tex/, manifest.json
```
  그 다음 에디터를 닫고 `build_level.py` (위 "처음 한 번"). 메시·재질만 바꿨으면 열린 에디터에서 `Scripts/cockpit/ck_reimport.py` 로 다시 가져오기만 해도 된다.
  `layout.py` = 모든 치수 (한 곳), `make_textures.py` = 판 글자·계기판·ADI 볼, `model_blender.py` = 형상, `ue_cockpit.py` = 언리얼 재질·배치,
  `fit_exterior.py` = F-16 겉 껍질 안쪽 치수 측정 (우리 조종석이 껍질 밖으로 안 튀어나오게).
- 재질: 한 마스터 `M_CkSurface` (글자 아틀라스 + 뒤 조명, 모서리 마모·오목 그늘 = 정점색, 얼룩 = UV1, 천 노멀) + 칸마다 인스턴스. 유리 2 종.
- 노출: 바깥 기준 EV100 2 (해 10 lux 기준, 11-04 PIE 에서 측정), 아래를 보면 1.5 스톱까지만 밝아짐 (하늘이 하얗게 날아가지 않게) + 로컬 노출 + 조종석 안 약한 보조등.

## 한계
- 에디터 안 Play (PIE) 에서만 동작 (Python 은 패키지 게임에서 안 됨).
- **JSBSim 땅은 어디나 191 ft 평지**. 실제 지형 모드에서 산은 보이기만 하고 비행 모델은 모른다.
  대신 언리얼이 10 Hz 로 기체 아래를 레이 캐스트해서 HUD 전파고도(R)를 실제 지형 기준으로 보여 주고, 지형 아래로 들어가면 일시정지 + "TERRAIN" (R/T 로 다시 시작).
  착륙·이륙은 활주로(=JSBSim 땅)에서만 맞다.
- `photo` 모드의 위성사진은 10 m 해상도라 낮게 날면 흐림. 활주로 주변만 사진 텍스처. 격자 모드엔 건물·산 없음.
- **VR 은 실제 헤드셋으로 시험하지 않음** (OpenXR 런타임·헤드셋 없음).
- Play 새 창: 기본값을 "새 에디터 창"으로 해 두고, 창이 뜨면 `sim_client` 가 창 제목 `[NetMode:` 로 찾아 최대화 (Alt+P 합성 키로 확인: 1080×1920 화면에서 최대화됨).
  점검 스크립트(-GyroSimVerify)는 Python 으로 Play 를 시작해서 뷰포트 안 Play 를 쓴다.
- 조종석: 보이는 계기·화면·등은 모두 실제 값 (장식 스위치는 없앰). 특정 기종의 정확한 복제가 아님. HUD 글자 뒤에는 어두운 판이 있다 (11-05 가독성: 밝은 구름 앞에서도 읽히게. 실제 HUD 에는 없음 — `hud.HUD_PLATE`, `build_level.HUD_PLATE`).
  눈 위치(RIG_EYE)는 추정, VR 헤드셋으로 손 위치가 맞는지 **아직 확인 못 함**. 추적 시점의 겉모습은 여전히 FlightGear F-16 (캐노피 안에 우리 앞 바우가 보임 — 실제 F-16 엔 없음).
