# 손잡이 ↔ 본체 연결 규격 (스틱 · 스로틀 공통)

본체(짐벌, 스로틀 레버) 설계 쪽은 이 규격만 맞추면 손잡이 S/M/L 어느 것이든 끼워진다. 모델: `grips.py` 의 `TUBE_*`, `BOLT_*`, `KEY_*` 값.

| 항목 | 값 |
|---|---|
| 관 | 알루미늄 원관 **바깥 Ø20.0, 두께 2.0 (안 Ø16)**. 스틱과 스로틀 모두 같은 관 (스로틀도 20×20 각재가 아니라 Ø20 관으로 정함) |
| 끼우는 깊이 | 관 끝이 손잡이 바닥면(소켓 입구)에서 **40 mm** 안으로 들어감. 손잡이 소켓 구멍 Ø20.4 |
| 고정 볼트 | **M4 × 30 둥근머리(ISO 7380) + M4 너트**, 좌우(y) 방향으로 관을 관통 |
| 볼트 위치 | 볼트 중심 = **관 윗끝에서 15 mm 아래** = 손잡이 바닥면에서 25 mm 위. 관에 Ø4.3 구멍을 지름 방향(좌우)으로 뚫음 |
| 돌림 막이 (키) | 관 윗끝 **뒤쪽(−x, 조종사 쪽)** 에 폭 4 × 깊이 6 mm 홈을 쇠톱 두 번 + 줄로 냄. 손잡이 소켓 맨 위 뒤쪽 리브(폭 3.8, 높이 6)가 이 홈에 들어감 → 볼트 구멍이 앞뒤로 정확히 맞고 볼트에 비틀림이 덜 걸림 |
| 선 | 4가닥 (5 V, GND, SDA, SCL) 차폐선, 바깥 Ø6 이하 권장. **관 안으로** 올라와 손잡이 안 PCF8574 로. 관 아래쪽은 본체 설계에서 선 나갈 구멍(Ø8 정도)을 관 옆에 냄 |
| 손잡이 아래 공간 | 손잡이 바닥면 바깥지름 약 Ø34 (목 부분). 바닥면 아래 관 둘레 Ø40 안에는 본체 부품을 두지 않음 (부츠는 가능) |
| 하중 (설계값) | 손잡이 꼭대기에 200 N (세게 당김). 관에는 손잡이 바닥면에서 약 29 N·m 굽힘 (M 크기, 꼭대기 약 145 mm) — Ø20×2 관 응력 약 62 MPa (6061-T6 항복 약 240 MPa). 짐벌 쪽 모멘트는 본체 설계에서 따로 계산 |

방향: x = 앞, y = 왼쪽, z = 위. 스틱 손잡이는 오른손용(엄지 = 왼쪽 위), 스로틀은 왼손용(엄지 = 오른쪽 안쪽).
손잡이 높이(바닥면→꼭대기)는 크기마다 다름: `parts.json` 의 `sizes.<S|M|L>.<stick|throttle>.height`.
